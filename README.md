One funny one-line resignation letter for make.fun's "The One-Line Exit" bounty, $2 in USDC. A pure-stdlib Python program writes the letter to `/output/entry.txt`: an elevator operator who spent four years going up in this company without ever once being promoted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
